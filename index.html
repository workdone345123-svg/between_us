Set up your board

Your board's data lives in a free Firebase project that only you control. Do these steps once, on a laptop if you can.

  1. Open console.firebase.google.com, tap Create a project, give it any name, and turn Google Analytics off.
  2. In the left menu, open Build → Firestore Database and tap Create database. Pick a location near you (for Pakistan, asia-south1) and choose production mode.
  3. In Firestore, open the Rules tab, replace everything with the rules below, and tap Publish.
    rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /rooms/{roomId}/{coll}/{docId} { allow read, write: if request.auth != null && roomId.size() >= 20; } } }
  4. Open Build → Authentication, tap Get started, then under Sign-in method choose Anonymous and turn it on.
  5. Open Project settings (the gear icon), scroll to Your apps, tap the web icon </>, register the app with any nickname, and copy the firebaseConfig block.
  6. Paste that block here and create the board.
